# Plan TheorySocket prototype

Use before assigning TheorySocket implementation work.

## Procedure

1. Define prototype scope and non-goals.
2. Identify command/event contract version and fixtures.
3. Define auth/session binding assumptions.
4. Define job status, log/event chunks, cancellation, final receipt pointer, reconnect, and idempotency behavior.
5. State clearly that TheorySocket is transport, not deployment authority.
6. Define validation and first assignment.
