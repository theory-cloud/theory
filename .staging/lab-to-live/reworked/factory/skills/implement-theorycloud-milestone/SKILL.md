# Implement a TheoryCloud milestone

Use only for parent-owned Factory repo changes that have been scoped and authorized.

## Allowed surfaces

- Factory docs and decision ledgers.
- Factory contracts and fixtures.
- Factory validation scripts.
- Factory implementation-wave records.
- Factory repository enumeration.
- Factory `.codex` stack and skills.
- Parent release/rollback plans and readiness reports.

## Not allowed

Do not use this skill to patch submodule source, framework code, repo-local agents, AWS state, DNS, account settings, runner credentials, or live receipts.

## Procedure

1. Confirm the milestone and allowed file scope.
2. Check current git status.
3. Make only the authorized Factory changes.
4. Run validation relevant to the changed artifacts.
5. Report changed files, validation, and any follow-up assignments.
6. Memory-append durable decisions or surprising constraints.

## Output

```markdown
# Implemented Milestone: <name>

## Changed files
## Validation
## Open follow-ups
## Memory-worthy decisions
```
