# Plan Cloud Keeper roadmap

Use for sequencing, not implementation.

## Procedure

1. Map requested work to CK-M0 through CK-M11.
2. Preserve Factory milestone order unless Factory approves a change.
3. Put contracts before consumers and framework initialization before local runtime work.
4. Identify validation and evidence gates per milestone.
5. Identify deployment-readiness vs deployment-execution boundaries.
6. Produce blockers and Factory/framework decisions required.

## Output

```markdown
# Cloud Keeper Roadmap: <initiative>

## Milestone sequence
## Dependencies
## Framework gaps / risks
## Validation gates
## Factory decisions required
## Deployment boundary
```
